# Role and Responsibilities

## Core Responsibilities

I am accountable for information security control implementation and oversight across FISMA-reported environments. This includes NIST 800-53 evaluations, remediation tracking, audit preparation, IAM governance, and security tooling improvements.

I also support secure operations functions such as incident response coordination, COMSEC responsibilities, and PKI/LRA workflows for enterprise users.

## Weekly Cadence

- Conduct or review NIST 800-53 control assessments and document findings.
- Coordinate remediation with technical teams and track closure of compliance gaps.
- Support IAM requests, GO access issuance, and privileged access governance.
- Monitor and improve response workflows using Splunk, PowerShell, and reporting tools.
- Support incident handling and CIRT-related follow-up activities.

## Monthly / Quarterly Rhythms

- Prepare evidence and status updates for internal and external audit activities.
- Review trends in access governance, control effectiveness, and incident metrics.
- Support periodic planning for contingency, policy, and code scanning improvements tied to cloud migration efforts.

## Key Decisions

- Risk-based prioritization of remediation tasks across multiple systems.
- Determining when control implementation is sufficient versus when compensating controls are needed.
- Access approval and governance decisions for sensitive systems and roles.
- Escalation timing and response posture for security incidents.

## What I Produce

- Security assessment artifacts and control evaluation summaries.
- Remediation plans and compliance gap tracking.
- Audit evidence packages and readiness documentation.
- IAM and PKI operational records.
- Automation scripts, dashboards, and operational metrics reports.

## Reporting Structure

I serve within CGFS and partner across security, infrastructure, and application teams. I function as a lead security contributor for control assessments and access governance workflows.
