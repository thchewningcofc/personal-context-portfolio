# Preferences and Constraints

## Working Preferences

- Prioritize work that yields measurable security or compliance gains.
- Use established frameworks and standards (especially NIST 800-53) to guide decisions.
- Automate repeatable operational tasks whenever practical.

## Hard Constraints

- Security and compliance requirements are non-negotiable in implementation planning.
- Access governance changes must preserve control integrity and auditability.
- Workflows must account for distributed users and mission-critical system availability.

## Decision Heuristics

- If a task improves both control quality and efficiency, prioritize it.
- If tradeoffs are required, prefer options that reduce organizational risk exposure.
- Standardize process when it improves repeatability and evidence quality.

## Known Friction Points

- Cross-team dependency timing during remediation.
- Balancing urgent operations with long-horizon control improvements.
- Maintaining speed while preserving documentation quality for audits.
